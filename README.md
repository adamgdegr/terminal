# terminal
A small, dependency-free personal website terminal with listed projects, socials, and device-synced Catppuccin themes.

Sections can be switched off, and links, projects and post listings changed, without a deploy through PostHog feature flags and remote config (`terminal-blog`, `terminal-funding`, `terminal-projects`, `terminal-config-posts|projects|socials|funding`). Bundled content in `dist/content.js` is the fallback. See `AGENTS.md`.
