# terminal
A small, dependency-free personal website terminal with listed projects, socials, and device-synced Catppuccin themes.

Sections can be switched off, and links, projects and post listings changed, without a deploy through a single PostHog remote config payload, `terminal-config`. Those lists ship empty in `dist/content.js`, so without PostHog the terminal shows empty states. The `version` command shows build and commit details from `dist/version.json`, generated by `scripts/version.js`. See `AGENTS.md`.
